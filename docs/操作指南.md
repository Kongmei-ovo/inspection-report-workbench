# 验货报告工作台操作指南

## 第一次打开

1. 下载与你电脑匹配的试用包。Windows 电脑用 windows-x64。Mac 在苹果菜单的「关于本机」查看芯片，Apple M 系列用 macos-arm64，Intel 用 macos-intel。
2. 解压整个 ZIP，保留解压目录里的所有文件。Windows 双击 InspectionWorkbench.exe。Mac 双击「启动工作台.command」。
3. 默认浏览器会打开工作台。如果没有自动打开，把启动窗口中 Workbench 后面的网址复制到浏览器。关闭启动窗口会退出工具。

试用包没有商业代码签名，系统可能提示来源警告。请先确认压缩包来自本项目 GitHub Release 或由项目负责人转发，再按系统提示处理。公司电脑如有安装限制，请联系管理员。无需另装 Python，处理文件也无需联网。

## SQC 验货报告

1. 在「备货单」添加系统生成的 PDF。可导入多份，包括不同月份。
2. 在「QC 原始报告」添加 Excel 文件，点选要处理的报告。
3. 查看每个原 PO 的匹配状态。展开「查看备货明细」核对品名、颜色、规格、数量和来源。没有匹配时，可添加其他 PDF 后重查。取消勾选可从本次成品移除该 PO。
4. 点击「导出 Excel」。打开文件核对 PO、日期、附图和快检结果。日期及实测数据沿用原报告。超过 5 MB 时，网页会提示检查。

## 装柜报告

1. 添加备货 PDF，切到「装柜报告」。先选发票，再选本次要做的 PO。
2. 核对表格里的品名和数量。程序会将该 PO 的跨页明细汇总，数量取产品数量列。按实际情况填写供应商、检验员、日期、柜号和封条号。
3. 添加照片、ZIP 或一个照片文件夹。可以展开「浏览已导入照片」，在看图时直接分配位置。分配后检查柜号和封条图是否与填写内容一致。
4. 点击「导出 Word」并检查排版。字段或照片不齐时，可下载草稿继续核对。

## 试用时请留意

- 备货单目前支持与已有样例同版的文字 PDF。扫描图片 PDF 暂不支持。
- 网页刷新或关闭后会清空本次操作，导出后请确认文件已经下载。
- 反馈问题时可以说明是哪一步、期望结果和实际结果。发送订单号、照片或文件前请按公司要求做脱敏。

## 更新软件

首次从 v0.1.2 升级时，在 GitHub 发布页重新下载对应平台的新版 ZIP。从 v0.2.0 起，可以在工作台左下角点击「检查更新」。发现新版后，先导出正在处理的报告，再点「下载并打开新版」。新版装到当前用户目录，原程序和已导出的报告会保留。原启动入口下次打开时会优先启动已安装的新版。

检查和下载更新需要联网访问 GitHub。工作台只查询公开版本信息和下载程序包，工作文件仍在本机处理。若公司网络拦截 GitHub，可从发布页手动下载。
